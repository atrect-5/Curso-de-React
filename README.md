# React Practice
### In this repository, you will find my React practice created for Azul School

This project was made with create-react-app.

This practice performs a CRUD operation on a movie list (Movie Information). This app allows you to view the complete list of movies and filter them by category, view specific information about a movie, edit the information of a movie, and delete a movie from the list.

The API used in this practice can be found at: https://github.com/atrect-5/Curso-Node.js  
You can also see the project with github pages at: https://atrect-5.github.io/Curso-de-React

> Node version used for the project: v20.17.0  
> npm version used for the project: 10.8.2

In the project directory, you can run:  
##### `npm start`

Runs the app in development mode.  
Open http://localhost:3000 to view it in your browser.
